# Turnstone content, batch 1, version 2 (15 Oct 2026)

Original reference data for SPEC §12 (missions), §22 (Traitor tasks) and the Milestone 5 Faithful decoy pool.

- `missions.json`: 37 missions across all seven categories, including Christmas and Halloween packs. Fields: id, title, category, format (teams, individuals or whole-group), players, durationMinutes, minimumAge, materials, setUp, rules, scoring, winner, maxPot, accessibility, plus set-up helpers: summary (one line for plan cards), location (indoor, outdoor, remote), prep (none, ahead, just-before), seated (playable entirely seated), locationNotes (an extra instruction shown only when the mission is played in that location), teamSize (team missions only) and potEntry. potEntry drives the organiser's Record result screen: pot = base + sum(count x pointsEach), clamped between 0 and maxPot. Pot values are points (display only).
- `seasons.json`: seasonal packs and the yearly date windows in which they are offered by default (month-day, inclusive; a window may cross the new year). Seasonal missions have category `seasonal` and a `season` id.
- `traitor-tasks.json`: 46 tasks matching `taskDefinitionSchema` (id, text, tags, minimumAge, difficulty). Adults-only tasks are 18+.
- `task-decoys.json`: 46 same-shaped Faithful decoy cards. The length distribution matches the task library: sorted lengths differ by at most 8 characters at every rank, and 20-character band counts differ by at most 2.
- `*-review.csv`: the same content, flattened for reading in a spreadsheet. The JSON files are the source.

Missions whose `winner` starts with "None" have no winner and cannot award a shield; every other mission names a team or player winner. Decoy cards are setting-neutral so they suit in-person and remote games.
