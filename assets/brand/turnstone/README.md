# Turnstone emblem assets

The emblem is symbol-only. Render the product title as separate text; the name is not embedded in these SVG files.
These files are source artwork only. The app continues to use the Stackstone mark until the owner approves the Turnstone emblem for product use.

- `turnstone-emblem-dark.svg`: transparent mark for dark backgrounds.
- `turnstone-emblem-light.svg`: transparent mark for light backgrounds.
- `turnstone-emblem-charcoal.png` and `turnstone-emblem-candle.png`: raster previews on the named backgrounds.
- `turnstone-emblem-preview.png`: both background treatments side by side.
- `favicon.svg`, `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, and `favicon.ico`: browser favicon assets.

All eight stones have the same size. The gold stone sits at approximately 1:30. The light-background version uses a darker gold-brown to maintain contrast.
